# Project 2: Iris Classification

A beginner-level Machine Learning project to classify Iris flowers based on their sepal and petal dimensions using the K-Nearest Neighbors (KNN) algorithm.

## Folder Structure
- `data/iris.csv`: The dataset used for training (exported from sklearn).
- `models/trained_model.pkl`: The saved KNN model.
- `main.py`: The main script to train and evaluate the model.
- `requirements.txt`: Required Python libraries.
- `report.txt`: Project internship report.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the script: `python main.py`
